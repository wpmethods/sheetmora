01 / Getting started

Install SheetMora

You need an active WooCommerce store, a Google account with access to the destination spreadsheet, and a WordPress administrator account.

  1. Install the Free plugin.

    In WordPress, open Plugins → Add New Plugin → Upload Plugin. Upload the SheetMora Free ZIP, install it and activate it.

  2. Install Pro if you have it.

    Upload and activate the separate SheetMora Pro ZIP. Keep the Free plugin active; it supplies the shared integration.

  3. Open SheetMora.

    Use the SheetMora menu or its Settings link in the Plugins list. For Pro, activate your key under SheetMora → Pro License.

Plugin requirementsWordPress 5.9+ · PHP 7.4+

Use WordPress and PHP versions supported by your installed WooCommerce release.

Google API connectionHTTPS + PHP OpenSSL

Both WordPress Address and Site Address should use HTTPS. Open the admin page securely too.

02 / Free edition

Set up your first Single Sheet Free

Free uses one Apps Script receiver and the WooCommerce Orders tab. You do not need your own OAuth app for this setup.

  1. Choose the orders and columns.

    Open SheetMora, choose trigger statuses, optionally choose product categories, and select your checkout fields. Click Save settings.

  2. Generate the receiver.

    Click Generate Google Apps Script and copy the entire script. It includes the selected schema and a private authentication secret.

  3. Open Apps Script from your spreadsheet.

    Create a spreadsheet, then open Extensions → Apps Script. Replace the starter code with the complete generated receiver and save.

  4. Deploy the script.

    Use Deploy → New deployment, choose Web app, execute as yourself and select Anyone for access where your Google account allows it. Review and complete Google's authorization flow. Google's web-app deployment guide ↗

  5. Save the deployed URL.

    Copy the web-app URL ending in /exec into SheetMora's Google Apps Script URL field, then save again.

  6. Test a matching order.

    Move a test order into one of the selected statuses. Allow the background delivery to run, then check its row in the spreadsheet.

Apps Script URL format
https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec
After changing columns

Save your fields, generate a fresh receiver and deploy the new script version. Existing headers must match the saved schema. Use a new destination or matching empty tab when changing the column layout.

Google Workspace policies can restrict public web-app access. If your account cannot provide the required deployment access, ask its administrator or use Pro API delivery. Keep the generated receiver private.

03 / Recommended Pro setup

Connect with Google Pro

The built-in connection service is already configured. For the standard setup, leave the developer options off and use Connect with Google.

  1. Prepare your first configuration.

    With Pro activated, open Configuration profiles. Keep Google Sheets API selected, choose your order rules and fields, and click Save configurations.

  2. Connect your account.

    Click Connect with Google, choose the Google account that should own the spreadsheet, review the requested permissions and consent.

  3. Create the destination.

    The optional Create a spreadsheet for my first API configuration if needed checkbox can create the first API destination after connection. Otherwise, use Create spreadsheet inside the saved profile.

  4. Or verify an authorized spreadsheet.

    Enter an already authorized spreadsheet ID or URL and click Verify & select. Use Refresh authorized sheets to refresh the app's file list.

  5. Send a test order.

    Move an order into a status matched by that profile. Google Sheets API delivery creates the needed tabs and headers automatically; no Apps Script is installed.

Access is limited to app-authorized files

Pasting any Drive URL does not grant permission to that file. Creating the spreadsheet from SheetMora is the simplest way to make an authorized destination. This release does not include a Google Picker for authorizing arbitrary existing files. About per-file Google access ↗

To change accounts, expand Disconnect or change Google account. Reconnecting the same account can reuse verified destinations; using a different account requires destination verification again.

04 / Workflows

Give each destination its own rules

Use Add configuration to create another complete workflow. Each profile owns its connection method, spreadsheet or script URL, statuses, categories, fields, sheet mode and optional webhook.

Example A

Main orders

Processing and completed orders → an API spreadsheet using Single Sheet.

Example B

Clothing team

Orders containing a Clothing product → another spreadsheet using Category-wise tabs.

  • Save before destination actions. Creating a spreadsheet, verifying a sheet or generating a receiver uses that profile's saved fields and settings.
  • One order can match multiple profiles. Every matching destination receives its own selected columns and retries independently.
  • Category filters select whole orders. An order qualifies if at least one item belongs to a chosen category. Its other line items remain included. Leave categories empty to accept all categories.
  • Duplicate rules creates a new workflow. Rules and fields are copied, while the live destination and webhook URL are cleared. Set the new destination and save.
  • Pause or remove carefully. Turn off Enable this configuration to pause it. Removal can be undone with Undo last removal before you save. Editing or pausing a profile invalidates its old queued delivery settings.
API and manual profiles can work together

The Setup guide selector changes the guidance shown on the page. Each saved profile keeps its own delivery method. A manual profile has one Apps Script URL and its own generated receiver.

06 / Columns

Columns must match existing headers

Changing fields changes the expected schema. SheetMora rejects mismatched headers instead of placing values under the wrong columns. Prepare a matching tab or a new spreadsheet after changing the layout. For manual delivery, also regenerate and redeploy the receiver.

07 / Integrations

Forward a profile to a webhook

  1. Expand Optional webhook forwarding inside the profile.
  2. Enable forwarding and enter a public HTTPS endpoint.
  3. Save configurations. Matching orders send the profile's selected fields as JSON.

The webhook receives order-field values directly, without an Apps Script authentication token or Google credentials. Category-wise profiles can include category-routing metadata. Your endpoint should accept JSON and return a successful HTTP status. Redirects are not followed.

Choose a trusted destination

Selected columns can contain customer contact details and notes. Check the destination's privacy policy and access controls before enabling forwarding.

08 / Your license

Manage Pro activation

Open SheetMora → Pro License, enter your purchased key and select Verify & activate. Activation is tied to the current store domain.

  • Verify an existing key: leave the replacement field empty to use your saved license.
  • Replace a key: enter the new key in the replacement field and submit verification.
  • Move a license: use Move or deactivate this license on the old domain, then activate it on the new domain, subject to your license's activation allowance.
  • Update both plugins as needed: keep Free installed and use a Pro version compatible with it. Back up the store before updating.

Pro features require an active plugin entitlement. The Google connection service itself does not validate or receive the Pro license key. License verification remains a separate action with WP Methods.

09 / Optional developer setup

Use your own Google OAuth app

Most stores can skip this section

The standard Pro connection uses SheetMora's built-in service. Leave both developer options off to use it.

  1. Prepare a Google Cloud project.

    Enable the Google Sheets and Google Drive APIs in the same project.

  2. Configure consent.

    Set up the app's branding, audience and permissions. Add your test accounts when testing an external app. Google's consent setup guide ↗

  3. Create a Web application client.

    Open Google Auth platform → Clients and create the client. Add the exact redirect URI shown by SheetMora to its authorized redirect URIs.

  4. Save your credentials in SheetMora.

    Under Developer setup, expand Use a Google OAuth app directly and enable Use my own Google OAuth app. Paste the Client ID and Secret from that same client, save and connect. Google displays a new secret at creation; keep your saved client configuration private. An empty Secret field keeps the matching saved secret.

Direct connections request openid, email and https://www.googleapis.com/auth/drive.file. Follow Google's web-server OAuth guidance for the complete setup and production requirements.

<?php
/** Standalone OAuth connection service. Deploy separately from the WordPress plugin. */
declare(strict_types=1);

require __DIR__ . '/src/class-sm-connection-service.php';

header('Cache-Control: no-store, private');
header('Pragma: no-cache');
header('Referrer-Policy: no-referrer');
header('X-Content-Type-Options: nosniff');
header("Content-Security-Policy: default-src 'none'; frame-ancestors 'none'");

try {
    if (($_SERVER['HTTPS'] ?? '') !== 'on' && getenv('SM_TRUST_HTTPS_PROXY') !== '1') {
        throw new \SMConnect\ServiceError('https_required', 400);
    }
    $input = [];
    $method = $_SERVER['REQUEST_METHOD'] ?? 'GET';
    if ($method === 'POST') {
        if (stripos($_SERVER['CONTENT_TYPE'] ?? '', 'application/json') !== 0) {
            throw new \SMConnect\ServiceError('json_required', 415);
        }
        $raw = file_get_contents('php://input', false, null, 0, 32769);
        if (!is_string($raw) || strlen($raw) > 32768) {
            throw new \SMConnect\ServiceError('request_too_large', 413);
        }
        $input = json_decode($raw, true, 16);
        if (!is_array($input)) {
            throw new \SMConnect\ServiceError('invalid_json', 400);
        }
    } else {
        $input = $_GET;
    }
    $service = \SMConnect\Service::fromEnvironment();
    $result = $service->dispatch(is_string($_GET['action'] ?? null) ? $_GET['action'] : '', $method, $input);
    if (isset($result['redirect'])) {
        header('Location: ' . $result['redirect'], true, 302);
    } else {
        header('Content-Type: application/json; charset=utf-8');
        echo json_encode($result, JSON_THROW_ON_ERROR);
    }
} catch (\SMConnect\ServiceError $error) {
    http_response_code($error->status);
    header('Content-Type: application/json; charset=utf-8');
    echo json_encode(['error' => $error->getMessage()]);
} catch (\Throwable $error) {
    // Do not print exception text: provider responses or credentials can appear in exceptions.
    http_response_code(500);
    header('Content-Type: application/json; charset=utf-8');
    echo '{"error":"service_unavailable"}';
}

<?php
/** OAuth broker: no WooCommerce orders are received, stored or forwarded here. */
declare(strict_types=1);

namespace SMConnect;

final class ServiceError extends \RuntimeException
{
    public int $status;

    public function __construct(string $message, int $status = 400)
    {
        parent::__construct($message);
        $this->status = $status;
    }
}

final class Service
{
    private \PDO $db;
    private string $key;
    private array $config;
    private $http;
    public const SCOPE = 'openid email https://www.googleapis.com/auth/drive.file';

    public function __construct(\PDO $db, string $key, array $config, ?callable $http = null)
    {
        if (strlen($key) !== 32 || empty($config['client_id']) || empty($config['client_secret']) || !self::publicHttps($config['url'] ?? '') || parse_url($config['url'], PHP_URL_QUERY)) {
            throw new ServiceError('invalid_service_configuration', 500);
        }
        $this->db = $db;
        $this->key = $key;
        $this->config = $config;
        $this->http = $http ?? [self::class, 'http'];
        $db->setAttribute(\PDO::ATTR_ERRMODE, \PDO::ERRMODE_EXCEPTION);
        $db->exec('PRAGMA busy_timeout=5000');
        $db->exec('PRAGMA journal_mode=WAL');
        $db->exec('CREATE TABLE IF NOT EXISTS records (bucket TEXT NOT NULL, id TEXT NOT NULL, document TEXT NOT NULL, expires INTEGER NOT NULL, PRIMARY KEY(bucket,id))');
        $statement = $db->prepare('DELETE FROM records WHERE expires < ?');
        $statement->execute([time()]);
    }

    public static function fromEnvironment(): self
    {
        $directory = realpath((string)getenv('SM_STORAGE_DIR'));
        $documentRoot = realpath($_SERVER['DOCUMENT_ROOT'] ?? __DIR__ . '/..');
        if (!$directory || !is_dir($directory) || !is_writable($directory) || ($documentRoot && strncmp($directory . DIRECTORY_SEPARATOR, $documentRoot . DIRECTORY_SEPARATOR, strlen($documentRoot) + 1) === 0)) {
            throw new ServiceError('private_storage_required', 500);
        }
        $key = base64_decode((string)getenv('SM_STORAGE_KEY'), true);
        if (!is_string($key)) {
            throw new ServiceError('invalid_storage_key', 500);
        }
        return new self(new \PDO('sqlite:' . $directory . '/connections.sqlite'), $key, [
            'url' => (string)getenv('SM_SERVICE_URL'),
            'client_id' => (string)getenv('SM_GOOGLE_CLIENT_ID'),
            'client_secret' => (string)getenv('SM_GOOGLE_CLIENT_SECRET'),
        ]);
    }

    public static function publicHttps(string $url): bool
    {
        $parts = parse_url($url);
        if (!is_array($parts) || ($parts['scheme'] ?? '') !== 'https' || empty($parts['host']) || isset($parts['user']) || isset($parts['pass']) || isset($parts['port']) || isset($parts['fragment'])) {
            return false;
        }
        $host = strtolower($parts['host']);
        return $host !== 'localhost' && strpos($host, '.') !== false && !filter_var($host, FILTER_VALIDATE_IP) && preg_match('/^[a-z0-9.-]+$/D', $host) === 1;
    }

    private static function text(array $input, string $name, int $maximum = 4096): string
    {
        $value = $input[$name] ?? '';
        if (!is_string($value) || strlen($value) > $maximum || preg_match('/[\x00-\x1f\x7f]/', $value)) {
            throw new ServiceError('invalid_' . $name);
        }
        return $value;
    }

    private static function random(): string
    {
        return bin2hex(random_bytes(32));
    }

    private function encrypt(array $data): string
    {
        $nonce = random_bytes(12);
        $tag = '';
        $encrypted = openssl_encrypt(json_encode($data, JSON_THROW_ON_ERROR), 'aes-256-gcm', $this->key, OPENSSL_RAW_DATA, $nonce, $tag, 'sm-connect-v1');
        if ($encrypted === false) {
            throw new ServiceError('storage_encryption_failed', 500);
        }
        return base64_encode($nonce . $tag . $encrypted);
    }

    private function decrypt(string $document): array
    {
        $raw = base64_decode($document, true);
        if ($raw === false || strlen($raw) < 29) {
            throw new ServiceError('invalid_connection', 401);
        }
        $json = openssl_decrypt(substr($raw, 28), 'aes-256-gcm', $this->key, OPENSSL_RAW_DATA, substr($raw, 0, 12), substr($raw, 12, 16), 'sm-connect-v1');
        $data = is_string($json) ? json_decode($json, true) : null;
        if (!is_array($data)) {
            throw new ServiceError('invalid_connection', 401);
        }
        return $data;
    }

    private function put(string $bucket, string $token, array $data, int $lifetime): void
    {
        $statement = $this->db->prepare('INSERT OR REPLACE INTO records (bucket,id,document,expires) VALUES (?,?,?,?)');
        $statement->execute([$bucket, hash('sha256', $token), $this->encrypt($data), time() + $lifetime]);
    }

    private function get(string $bucket, string $token): array
    {
        if (preg_match('/^[a-f0-9]{64}$/D', $token) !== 1) {
            throw new ServiceError('invalid_connection', 401);
        }
        $statement = $this->db->prepare('SELECT document FROM records WHERE bucket=? AND id=? AND expires>=?');
        $statement->execute([$bucket, hash('sha256', $token), time()]);
        $document = $statement->fetchColumn();
        if (!is_string($document)) {
            throw new ServiceError('invalid_connection', 401);
        }
        return $this->decrypt($document);
    }

    private function take(string $bucket, string $token): array
    {
        $this->db->exec('BEGIN IMMEDIATE');
        try {
            $data = $this->get($bucket, $token);
            $this->remove($bucket, $token);
            $this->db->exec('COMMIT');
            return $data;
        } catch (\Throwable $error) {
            $this->db->exec('ROLLBACK');
            throw $error;
        }
    }

    private function remove(string $bucket, string $token): void
    {
        $statement = $this->db->prepare('DELETE FROM records WHERE bucket=? AND id=?');
        $statement->execute([$bucket, hash('sha256', $token)]);
    }

    public static function http(string $url, array $body): array
    {
        // URLs come only from the fixed Google endpoints below.
        $handle = curl_init($url);
        curl_setopt_array($handle, [CURLOPT_POST => true, CURLOPT_POSTFIELDS => http_build_query($body, '', '&', PHP_QUERY_RFC3986), CURLOPT_RETURNTRANSFER => true, CURLOPT_FOLLOWLOCATION => false, CURLOPT_CONNECTTIMEOUT => 5, CURLOPT_TIMEOUT => 20, CURLOPT_SSL_VERIFYPEER => true, CURLOPT_SSL_VERIFYHOST => 2, CURLOPT_HTTPHEADER => ['Content-Type: application/x-www-form-urlencoded'], CURLOPT_PROTOCOLS => CURLPROTO_HTTPS]);
        $response = curl_exec($handle);
        $status = curl_getinfo($handle, CURLINFO_RESPONSE_CODE);
        curl_close($handle);
        $data = is_string($response) && strlen($response) <= 65536 ? json_decode($response, true) : null;
        if ($status < 200 || $status >= 300 || !is_array($data)) {
            if (is_array($data) && ($data['error'] ?? '') === 'invalid_grant') {
                throw new ServiceError('invalid_connection', 401);
            }
            throw new ServiceError('provider_unavailable', 502);
        }
        return $data;
    }

    private function location(array $data, array $query): string
    {
        return $data['callback'] . '&' . http_build_query($query, '', '&', PHP_QUERY_RFC3986);
    }

    public function dispatch(string $action, string $method, array $input): array
    {
        $getActions = ['authorize', 'callback'];
        if ($method !== (in_array($action, $getActions, true) ? 'GET' : 'POST') || !in_array($action, ['start', 'authorize', 'callback', 'exchange', 'refresh', 'disconnect'], true)) {
            throw new ServiceError('invalid_action_or_method', 405);
        }
        if ($action === 'start') {
            $callback = self::text($input, 'callback', 2048);
            $site = self::text($input, 'site_url', 2048);
            $state = self::text($input, 'state', 64);
            $challenge = self::text($input, 'challenge', 43);
            if (!self::publicHttps($callback) || !self::publicHttps($site) || preg_match('/^[a-zA-Z0-9]{64}$/D', $state) !== 1 || preg_match('/^[a-zA-Z0-9_-]{43}$/D', $challenge) !== 1) {
                throw new ServiceError('invalid_start_request');
            }
            $expected = rtrim($site, '/') . '/wp-admin/admin-post.php?action=sm_google_callback';
            if (!hash_equals($expected, $callback) || parse_url($site, PHP_URL_QUERY)) {
                throw new ServiceError('invalid_callback');
            }
            $data = ['callback' => $callback, 'site_url' => $site, 'state' => $state, 'challenge' => $challenge];
            $request = self::random();
            $this->put('request', $request, $data, 600);
            return ['authorization_url' => $this->config['url'] . '?action=authorize&request=' . $request];
        }
        if ($action === 'authorize') {
            $data = $this->take('request', self::text($input, 'request', 64));
            $state = self::random();
            $this->put('oauth', $state, $data, 600);
            return ['redirect' => 'https://accounts.google.com/o/oauth2/v2/auth?' . http_build_query(['client_id' => $this->config['client_id'], 'redirect_uri' => $this->config['url'] . '?action=callback', 'response_type' => 'code', 'scope' => self::SCOPE, 'access_type' => 'offline', 'prompt' => 'consent', 'state' => $state], '', '&', PHP_QUERY_RFC3986)];
        }
        if ($action === 'callback') {
            $data = $this->take('oauth', self::text($input, 'state', 64));
            if (isset($input['error'])) {
                return ['redirect' => $this->location($data, ['state' => $data['state'], 'error' => 'access_denied'])];
            }
            $code = self::text($input, 'code');
            if (!$code) {
                throw new ServiceError('missing_code');
            }
            $tokens = call_user_func($this->http, 'https://oauth2.googleapis.com/token', ['code' => $code, 'client_id' => $this->config['client_id'], 'client_secret' => $this->config['client_secret'], 'redirect_uri' => $this->config['url'] . '?action=callback', 'grant_type' => 'authorization_code']);
            if (!is_string($tokens['refresh_token'] ?? null) || !is_string($tokens['access_token'] ?? null) || !in_array('https://www.googleapis.com/auth/drive.file', explode(' ', $tokens['scope'] ?? ''), true)) {
                return ['redirect' => $this->location($data, ['state' => $data['state'], 'error' => 'permission_required'])];
            }
            $ticket = self::random();
            $this->put('ticket', $ticket, ['request' => $data, 'tokens' => $tokens], 120);
            return ['redirect' => $this->location($data, ['state' => $data['state'], 'ticket' => $ticket])];
        }
        if ($action === 'exchange') {
            $ticket = self::text($input, 'ticket', 64);
            $verifier = self::text($input, 'verifier', 128);
            $record = $this->get('ticket', $ticket);
            $challenge = rtrim(strtr(base64_encode(hash('sha256', $verifier, true)), '+/', '-_'), '=');
            if (strlen($verifier) < 43 || !hash_equals($record['request']['challenge'], $challenge)) {
                throw new ServiceError('invalid_proof', 401);
            }
            $record = $this->take('ticket', $ticket);
            $connection = self::random();
            $this->put('connection', $connection, ['request' => $record['request'], 'refresh_token' => $record['tokens']['refresh_token']], 15552000);
            return ['connection_token' => $connection, 'access_token' => $record['tokens']['access_token'], 'expires_in' => min(3600, (int)($record['tokens']['expires_in'] ?? 3600))];
        }
        $connection = self::text($input, 'connection_token', 64);
        $record = $this->get('connection', $connection);
        if ($action === 'disconnect') {
            $this->remove('connection', $connection);
            try {
                call_user_func($this->http, 'https://oauth2.googleapis.com/revoke', ['token' => $record['refresh_token']]);
            } catch (\Throwable $error) {
                // Local revocation still succeeds when Google's endpoint is temporarily unavailable.
            }
            return ['success' => true];
        }
        try {
            $tokens = call_user_func($this->http, 'https://oauth2.googleapis.com/token', ['client_id' => $this->config['client_id'], 'client_secret' => $this->config['client_secret'], 'refresh_token' => $record['refresh_token'], 'grant_type' => 'refresh_token']);
        } catch (ServiceError $error) {
            if ($error->getMessage() === 'invalid_connection') {
                $this->remove('connection', $connection);
            }
            throw $error;
        }
        if (!is_string($tokens['access_token'] ?? null) || !$tokens['access_token']) {
            throw new ServiceError('provider_unavailable', 502);
        }
        $this->put('connection', $connection, $record, 15552000);
        return ['access_token' => $tokens['access_token'], 'expires_in' => min(3600, (int)($tokens['expires_in'] ?? 3600))];
    }
}

# SheetMora Google connection service

Deploy this directory **separately** on an HTTPS PHP server. It is not part of the installable WordPress plugin ZIP and must not run from wp-content/plugins. The plugin also supports site-specific OAuth credentials when a hosted service is not wanted.

Requirements: PHP 8.0+, OpenSSL, cURL, PDO SQLite, HTTPS, and a writable private directory outside the document root. Configure your web server to disable directory listings, deny access to `src/`, and keep `display_errors` disabled. Configure request rate limiting for `action=start` (for example 10 requests/minute per IP) and request-size limits at the web server. Keep encrypted database backups private.

Set these environment variables on the server; never put actual secrets into the plugin:

- `SM_SERVICE_URL=https://connect-sheetmora.wpmethods.com/index.php` (no query string).
- `SM_GOOGLE_CLIENT_ID` and `SM_GOOGLE_CLIENT_SECRET` from a Google OAuth **Web application** client.
- `SM_STORAGE_DIR=/private/path/google-connect` (create it before starting).
- `SM_STORAGE_KEY`: base64 encoding of 32 random bytes. Generate with `php -r 'echo base64_encode(random_bytes(32));'`. Preserve this key securely; changing it invalidates saved connections.
- If TLS terminates at a trusted reverse proxy, set `SM_TRUST_HTTPS_PROXY=1` **only when the backend cannot be reached directly and the proxy enforces HTTPS**. The service deliberately does not trust arbitrary forwarded headers.

In Google Cloud, enable Google Sheets API and Google Drive API, configure branding/consent, and register exactly `https://connect-sheetmora.wpmethods.com/index.php?action=callback` as an authorized redirect URI. Request `openid`, `email`, and `https://www.googleapis.com/auth/drive.file`. Complete the applicable Google production/branding verification requirements and publish the app rather than leaving it in testing. Testing-mode grants can expire. Merchant stores must use HTTPS. Google authorization and token refresh do not call a license API. Pro feature entitlement and license management remain in the WordPress add-on.

On merchant sites set `SM_GOOGLE_CONNECT_URL` in wp-config.php or enter the URL in the Pro connection panel's developer setup. The service URL is public; the Google Client Secret and storage key remain server-side.

Flow: merchant administrator POSTs Connect Google → plugin creates session state bound to that administrator → service validates the HTTPS callback, state and handoff challenge and records a ten-minute OAuth request → Google consent → a two-minute one-time ticket returns to the same store callback → plugin exchanges that ticket using its PKCE handoff verifier → service returns an opaque connection handle and an access token. Google refresh tokens remain encrypted on this server. The plugin encrypts its connection handle and access token using WordPress salts. Google authorization codes/tickets are single-use. No Google tokens are placed in browser redirect URLs.

The refresh endpoint accepts only an unguessable connection handle and returns a short-lived Google token. Disconnect removes the handle and attempts Google revocation. Inactive records expire after 180 days. The broker never receives WooCommerce order data; orders travel directly between each store and Google Sheets. New broker records store the store URL, refresh token, and authorization/session metadata in authenticated encrypted records. License keys are not required or stored in new records. Publish a privacy policy explaining this processing and secure administrator access, database backups and operational logs. Avoid logging request bodies or query strings for OAuth routes.

Google references:
- https://developers.google.com/identity/protocols/oauth2/web-server
- https://developers.google.com/workspace/sheets/api/scopes
- https://developers.google.com/identity/protocols/oauth2/production-readiness/policy-compliance

Run the supplied standalone broker regression test before deployment. The included code is prepared for deployment; it does not create a Cloud project, provision a server, or claim Google verification has been completed.

The service accepts only the SheetMora encrypted record format. There is no previous-identity storage or credential fallback.


Deployment package 1.0.0: replace index.php and src/class-sm-connection-service.php together when deploying this package. Keep the existing environment variables, SM_STORAGE_KEY and private SQLite storage when replacing a working deployment. This service does not grant WordPress Pro entitlement.

11 / Troubleshooting
Find the next useful check
Read the full error, including its HTTP status and diagnostic code. Search this guide by that code to jump to a specific issue.

        
No orders appear in the spreadsheet
Check that the profile is enabled, has a ready destination, and matches the order's status and categories. Save its configuration, then move a test order into a selected status. Pro settings are independent from the Free configuration.
Review WooCommerce → Status → Scheduled Actions and Logs, using source sm. Background tasks must be able to run. Delivery makes at most three attempts per failed destination, then logs the failure. Old jobs are not a historical export.

        
Connect with Google is disabled
Confirm both WordPress Address and Site Address use HTTPS and that the browser is on HTTPS. For a local store, enable and trust its SSL certificate first. PHP OpenSSL and a valid connection provider are also needed.

        
HTTP 200 · unexpected_response
A successful HTTP status can still contain an HTML page, a hosting warning or an unexpected JSON response. For a custom service, check its exact HTTPS /index.php endpoint. Check redirects, cache rules and firewall challenges affecting WordPress's request.
The OAuth start endpoint must return JSON containing an authorization URL. Ask the server administrator to inspect the response type and logs without publishing credentials, tokens or complete authorization URLs.

        
private_storage_required
On a self-hosted service, check that SM_STORAGE_DIR resolves to an existing writable directory outside the document root. The PHP worker needs traversal permission on every parent directory. Its effective open_basedir must permit the storage path. Keep the existing key and database.

        
HTTP 405 · invalid_action_or_method
Opening index.php without an OAuth action can produce this response normally. Initiate authorization with Connect with Google in WordPress. If a real start request gets this code, inspect method-changing redirects and endpoint rewrites.

        
invalid_callback / redirect_uri_mismatch
Check HTTPS and the WordPress Address used by the store. In Google Cloud, the redirect URI must exactly match the actual callback: the WordPress callback for a direct app, or the service's callback for hosted OAuth. Check the scheme, path, query and trailing slash.

        
Client, grant or connection errors
For invalid_client, verify that Client ID and Secret belong to the same OAuth Web application. For an expired or revoked grant, connect again. Keep the same WordPress login session while completing consent; OAuth state expires and is single-use. Changing WordPress salts also requires reconnection.

        
Headers or columns do not match
Use columns matching the saved field schema, or create a fresh destination. Avoid manually rearranging headers. For Apps Script, regenerate and redeploy the full receiver after changes. Separate profiles with different fields should use separate tabs.

        
The spreadsheet is missing or cannot be verified
Confirm you connected the correct Google account and approved file access. Refresh authorized sheets. An arbitrary shared spreadsheet URL is not automatically authorized for the app. Create a spreadsheet from the saved profile, or select a file already authorized for this app.

        
Network, provider or rate-limit errors
Check outbound HTTPS, DNS, cURL and certificate trust on the relevant server. For provider_unavailable on your own service, check its access to Google. For rate limits, allow time before retrying and review Google API quotas.

13 / Common questions
A few useful answers

        
Do I need Apps Script with Pro?
API profiles work without Apps Script. Manual Pro profiles still use one generated receiver per configuration.

        
Will installing SheetMora export old orders?
No automatic historical export is included. Delivery is triggered by matching status changes, with queued jobs rechecking current order and configuration rules.

        
Is a category filter the same as Category-wise tabs?
A category filter decides whether an order qualifies, and is available in Free. Category-wise sheet mode is a Pro feature that copies a qualifying order into tabs for its categories.

        
Why can one order appear in multiple places?
Multiple matching profiles and Category-wise routing can intentionally write an order to several destinations. Within a destination tab, Order ID is used to update an existing row.

        
Are settings from the earlier plugin identity imported?
SheetMora uses its current settings and credential formats. Configure SheetMora, activate Pro where applicable, reconnect Google and generate a current receiver for manual delivery.
